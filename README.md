# Playlist Maker

Android-приложение плейлиста с поиском треков, их прослушиванием, созданием плейлистов. Реализовано на Kotlin с использованием Jetpack Compose и архитектуры MVVM.

## Требования к окружению

| Параметр | Значение |
| :--- | :--- |
| Android Studio |
| JDK | 11 |
| minSdk | 29 |
| targetSdk / compileSdk | 37 |
| Сборка | Gradle (Kotlin DSL), Version Catalogs |

## Стек технологий

-   **UI:** Jetpack Compose, Material3
-   **Архитектура:** MVVM, Clean Architecture (Data / Domain / UI)
-   **DI:** Koin 4.0.2
-   **Асинхронность:** Kotlin Coroutines, Flow
-   **Навигация:** Navigation Compose
-   **Сериализация:** Gson

## Реализованный функционал

### Экран поиска
-   Поиск треков по названию или имени исполнителя (без учета регистра).
-   Фильтрация и форматирование данных (mm:ss) выполняются в слое Data/Domain.
-   Обработка состояний UI: Initial, Searching, Success, Fail.
-   Индикация загрузки и обработка ошибок без падения приложения.
-   Эмулятор данных (MockStorage) для автономной работы.

### Экран настроек
-   Кнопка «Поделиться»: открытие системного диалога шеринга.
-   Кнопка «Написать разработчикам»: запуск почтового клиента.
-   Кнопка «Пользовательское соглашение»: открытие ссылки в браузере.

### Навигация
-   Единый граф навигации (NavHost) в MainActivity.

## Сборка и запуск

1.  Клонируйте репозиторий:
    ```bash
    git clone <https://github.com/Grechka00041/Playlist-maker.git>
    cd playlist-maker
    ```

2.  Откройте проект в Android Studio. Дождитесь завершения синхронизации Gradle.

3.  Убедитесь, что в настройках проекта (`File > Project Structure > SDK Location`) установлена JDK версии 11.

4.  Запустите приложение на эмуляторе (API 29+)или физическом устройстве.

## Структура модулей

-   `data`: Источники данных (MockStorage), сетевой клиент, DTO, реализация репозиториев, DI-модули.
-   `domain`: Интерфейсы репозиториев, доменные модели, бизнес-логика.
-   `ui`: Экраны (Compose), ViewModel, навигация, тема оформления.
