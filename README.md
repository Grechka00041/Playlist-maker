# Playlist Maker

Android-приложение для поиска музыки, создания плейлистов и управления избранными треками. Разработано на Kotlin с использованием Jetpack Compose и архитектуры MVVM + Clean Architecture в рамках курса от Yandex.

##  Дизайн-макет

Приложение реализовано в строгом соответствии с дизайн-системой. 
Все отступы, типографика, цвета и состояния UI элементов соответствуют макету:
 [**Открыть макет Playlist Maker в Figma**](https://www.figma.com/design/p0tFHLFx0XBI7BijypwVjW/Playlist-Maker?node-id=2229-3130&t=gd1mUIuuTwcEJOwn-0)

## Стек технологий

-   **UI:** Jetpack Compose, Material3, Coil (загрузка изображений)
-   **Архитектура:** MVVM, Clean Architecture (Data / Domain / UI)
-   **DI:** Koin 4.0.2
-   **Асинхронность:** Kotlin Coroutines, Flow, StateFlow
-   **Навигация:** Navigation Compose
-   **Локальное хранилище:** Room (SQLite), DataStore Preferences
-   **Сериализация:** Gson
-   **Сеть:** Retrofit (для iTunes Search API)

##  Реализованный функционал

###  Экран поиска
-   Поиск треков через iTunes Search API по названию или исполнителю.
-   История поисковых запросов: сохранение последних 10 запросов в DataStore.
-   Автодополнение из истории при фокусе на поле поиска.
-   Обработка состояний UI: Initial, Searching, Success (список/пусто), Fail (ошибка сети).
-   Форматирование длительности трека (мм:сс) в слое Domain.

###  Избранное
-   Добавление/удаление треков в избранное одним нажатием.
-   Постоянное хранение избранного в локальной БД (Room).
-   Экран «Избранное» с реактивным списком (Flow).
-   Удаление из избранного долгим нажатием на элемент списка.
-   Пустое состояние с тематической иллюстрацией.

###  Детали трека
-   Просмотр обложки, названия, исполнителя и длительности.
-   Кнопка добавления в плейлист (ModalBottomSheet со списком плейлистов).
-   Индикация статуса «Избранное» (сердечко).

###  Плейлисты
-   Создание новых плейлистов с названием, описанием и обложкой.
-   Выбор обложки из галереи устройства.
-   Список всех созданных плейлистов.
-   Экран деталей плейлиста: обложка, метаданные, список треков.
-   Добавление треков в плейлист через экран деталей трека.
-   Связь «многие-ко-многим» через таблицу CrossRef в Room.

###  Настройки и Тема
-   Переключение светлой/темной темы с сохранением выбора в DataStore.
-   Тема применяется ко всему приложению мгновенно без перезапуска.
-   Адаптивные цвета UI (семантические токены Material3).
-   Действия: «Поделиться», «Написать в поддержку», «Пользовательское соглашение».

##  Структура модулей

-   `data`: Источники данных (Retrofit, Room, DataStore), DTO, мапперы, реализация репозиториев, DI-модули.
-   `domain`: Интерфейсы репозиториев, доменные модели (Track, Playlist), бизнес-логика (UseCases/RepositoryImpl).
-   `ui`: Экраны (Compose), ViewModel, навигация (NavHost), тема оформления, ресурсы.

##  Сборка и запуск

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/Grechka00041/Playlist-maker.git
    cd playlist-maker
    ```
2.  Откройте проект в Android Studio. Дождитесь завершения синхронизации Gradle.

3.  Убедитесь, что в настройках проекта (`File > Project Structure > SDK Location`) установлена корректная версия JDK.

4.  Запустите приложение на эмуляторе (API 29+) или физическом устройстве.

> **Примечание:** Для работы поиска требуется активное интернет-соединение. Остальной функционал (плейлисты, избранное, настройки) работает офлайн.
